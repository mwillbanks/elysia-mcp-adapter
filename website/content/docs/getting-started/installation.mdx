## Requirements

- Elysia `>=1.4.0`
- Node.js `>=20.11` or Bun `>=1.1`
- TypeScript `>=5.8` for TypeScript projects
- Native ESM

## Install the adapter

```npm
npm install @mwillbanks/elysia-mcp-adapter elysia
```

`elysia` is a peer dependency. The adapter does not bring another application framework or a full MCP framework into your runtime.

## Add the plugin

```ts
import { mcp } from '@mwillbanks/elysia-mcp-adapter'
import { Elysia } from 'elysia'

const app = new Elysia().use(mcp())
```

This installs six fluent registration methods and the MCP HTTP endpoint:

- `.mcpTool()`
- `.mcpResource()`
- `.mcpPrompt()`
- `.mcpSkill()`
- `.mcpInterceptor()`
- `.mcpEvent()`

The default endpoint is `/mcp`.
Skills, interceptors, and events require their corresponding extension options.
See the [extension guides](/docs/extensions) for revision selectors and host responsibilities.

## Optional integrations

Install only the integrations your application uses:

```npm
npm install @elysia/openapi
```

```npm
npm install @elysiajs/bearer
```

```npm
npm install @elysiajs/opentelemetry
```

OpenAPI route metadata and schemas are reused by the adapter. Bearer authentication hooks and OpenTelemetry instrumentation remain part of the same Elysia lifecycle. See [Route-backed Tools](/docs/core-concepts/route-backed-tools), [Security](/docs/core-concepts/security), and [Transportation](/docs/core-concepts/transportation) for complete examples.
