## Requirements

- Elysia `>=1.4.0`
- Node.js `>=20.11` or Bun `>=1.1`
- TypeScript `>=5.8` for TypeScript projects
- Native ESM

## Install with Bun

```bash
bun add @mwillbanks/elysia-mcp-adapter elysia
```

Or use your Node.js package manager:

```bash
npm install @mwillbanks/elysia-mcp-adapter elysia
```

`elysia` is a peer dependency. `@elysiajs/openapi` and `@sinclair/typebox` are supported optional peers when your application already uses them.

## Add the plugin

```ts
import { mcp } from '@mwillbanks/elysia-mcp-adapter'
import { Elysia } from 'elysia'

const app = new Elysia().use(mcp())
```

This installs three fluent methods on the Elysia instance and registers the MCP HTTP endpoint:

- `.mcpTool()`
- `.mcpResource()`
- `.mcpPrompt()`

The default endpoint is `/mcp`. Continue to the [Quick Start](/docs/getting-started/quick-start) to expose a route.
