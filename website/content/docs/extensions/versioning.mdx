title: Versions and support manifest
description: Select immutable extension implementations and audit their upstream provenance.
---

Every extension accepts `current`, `draft`, or a supported `YYYY-MM-DD`. Unsupported dates fail while the plugin is constructed and the error lists valid choices.

The package exports `MCP_EXTENSION_SUPPORT`. Each entry records its status, inclusion date, upstream repository and revision, applicable package version, and schema hash. This makes the exact wire contract auditable without making private specification packages runtime dependencies.

Aliases never advance at runtime. Updating one requires a reviewed source, fixture, test, and documentation change. The scheduled upstream watcher reports drift; it does not rewrite aliases.
