[MCP Extension Support Matrix](https://modelcontextprotocol.io/extensions/client-matrix).

Experimental selectors pin reviewed Git revisions. They do not track branches, tags, or semver ranges. Upgrading a pin is a compatibility review, not a dependency update. Server variants remain legacy-only; configuring them with modern transport fails during option normalization.
