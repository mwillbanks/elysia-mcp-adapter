title: Interceptors examples
description: Test local chains and an isolated remote interceptor service.
---

The [experimental workspace](https://github.com/mwillbanks/elysia-mcp-adapter/tree/main/examples/experimental) contains local chain and remote service examples. Its client sends real requests through `app.handle(new Request(...))`. The child-process service runs on loopback and exits with the example.

Run the workspace checks from the repository root:

```bash
bun --bun run --cwd examples/experimental typecheck
bun --bun run --cwd examples/experimental test
bun --bun run --cwd examples/experimental build
bun --bun run --cwd examples/experimental smoke
```

The [server](https://github.com/mwillbanks/elysia-mcp-adapter/tree/main/examples/experimental/server.ts) shows registration. The [service](https://github.com/mwillbanks/elysia-mcp-adapter/tree/main/examples/experimental/interceptor-service.ts) and [remote client](https://github.com/mwillbanks/elysia-mcp-adapter/tree/main/examples/experimental/remote-interceptor.ts) exercise HTTP discovery and invocation.
