title: Server Variants
description: Deprecated experiment for selecting principal-bound MCP server views.
---

**Deprecated.** The Server Variants proposal closed without acceptance. The adapter retains its existing opt-in for this release, with removal planned in a later minor release. Use separate MCP endpoints when clients need different tool sets.

This opt-in requires classic MCP `2025-11-25`.

Existing users can review [migration guidance in the quick start](/docs/extensions/experimental/server-variants/quick-start), the [configuration reference](/docs/extensions/experimental/server-variants/configuration), and the [legacy example](/docs/extensions/experimental/server-variants/examples).
