---
title: Trust Annotations
description: Carry experimental trust and evidence references in MCP tool results.
---

Trust Annotations describe whether tool output is sensitive or untrusted and can carry a reference to evidence. The experimental annotation is available in tool results over classic and modern MCP. The adapter validates and preserves these fields. It does not retrieve evidence or establish trust.

Add `io.modelcontextprotocol/trust-annotations` to result `_meta`. See the [quick start](/docs/extensions/experimental/trust-annotations/quick-start), [configuration and host responsibilities](/docs/extensions/experimental/trust-annotations/configuration), and [examples](/docs/extensions/experimental/trust-annotations/examples).
