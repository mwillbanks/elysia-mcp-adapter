The [Events workspace](https://github.com/mwillbanks/elysia-mcp-adapter/tree/main/examples/events) contains the complete Bun example. It exercises replay polling, event-only POST SSE, durable SQLite webhook subscriptions, signed TLS delivery, secret rotation, and sequential process restart recovery.

Run its typecheck, tests, build, and smoke checks from the repository root:

```bash
bun --bun run --cwd examples/events typecheck
bun --bun run --cwd examples/events test
bun --bun run --cwd examples/events build
bun --bun run --cwd examples/events smoke
```

The [server](https://github.com/mwillbanks/elysia-mcp-adapter/tree/main/examples/events/server.ts) registers the extension and an event source. The [README](https://github.com/mwillbanks/elysia-mcp-adapter/tree/main/examples/events/README.md) explains cursor recovery, webhook ownership, callback verification, and the fixture's limits.
