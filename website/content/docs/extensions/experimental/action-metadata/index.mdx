---
title: Action Metadata
description: Attach experimental descriptions of tool effects and review requirements.
---

Action Metadata annotates tools with details about input destination and sensitivity, return source and sensitivity, outcome, and whether review is required. The experimental annotation is available in tool definitions over classic and modern MCP. It is descriptive metadata for hosts. It does not grant or replace authorization.

Use the `io.modelcontextprotocol/action-metadata` annotation when registering a tool. See the [quick start](/docs/extensions/experimental/action-metadata/quick-start), [configuration and host guidance](/docs/extensions/experimental/action-metadata/configuration), and [examples](/docs/extensions/experimental/action-metadata/examples).
