---
title: Server variants
description: Negotiate stable, principal-bound legacy server views.
---

Server Variants is deprecated. The upstream proposal closed without acceptance. This release
keeps its existing opt-in, and a later minor release will remove it. Publish distinct MCP endpoints
when clients need different tool sets.

The opt-in requires protocol `2025-11-25`, GET SSE, session deletion, and `extensions.variants`.

During initialize, the adapter authenticates the request, applies `visible`, applies `rank`, limits discovery, and stores the negotiated list against `MCP-Session-Id`. The first default variant must be stable unless the client requests experimental results. `io.modelcontextprotocol/server-variant` request metadata takes precedence over `MCP-Server-Variant`.

The selected variant binds tool, resource, and prompt registries. It also binds pagination cursors and resource subscriptions. Requests from another principal cannot reuse the session. `resources/unsubscribe` closes its provider iterator. Session deletion closes streams and subscriptions.

Use `core.subscriptions.provider` with `resources: true` for resource updates. Connect the session's GET `/mcp` SSE stream to receive variant-tagged notifications.
