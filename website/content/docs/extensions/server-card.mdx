title: Server Cards
description: Publish finalized, cacheable advisory server metadata with strict disclosure boundaries.
---

MCP lists Server Cards as Beta. Final SEP-2127 establishes the approved wire baseline.
The adapter preserves the approved schema and requires explicit opt-in.

`MCP_EXTENSION_SUPPORT.serverCard.current` selects the approved baseline. Its version record
reports `status: 'stable'` for compatibility with existing consumers.

```ts
import {
  MCP_SERVER_CARD_REVISION,
  MCP_SERVER_CARD_SCHEMA,
  mcp,
} from "@mwillbanks/elysia-mcp-adapter";

mcp({
  server: { name: "com.example/service", version: "build-42" },
  extensions: {
    serverCard: {
      version: MCP_SERVER_CARD_REVISION,
      card: {
        $schema: MCP_SERVER_CARD_SCHEMA,
        name: "com.example/service",
        description: "Example service",
        version: "build-42",
        remotes: [{ type: "streamable-http", url: "https://api.example.com/mcp" }],
      },
    },
  },
});
```

## Draft remote extension information

Set `extensions.serverCard.version` to `MCP_SERVER_CARD_DRAFT_REVISION` to publish the
`remotes[].extensions` map from the [pinned draft](https://github.com/modelcontextprotocol/ext-server-card/pull/55).
Each key is a prefixed extension identifier. Each value is a JSON object of public connection
information. The pinned schema permits nested objects, arrays, strings, integers, and booleans.
Publish only public data, such as public webhook verification keys. Private keys and embedded
credentials are rejected. Reserve JWK private member names for key material and omit them from
public extension information.

Clients negotiate support through live `server/discover` capabilities. Treat card entries as
advisory connection information.

The endpoint returns `application/mcp-server-card+json`, `Access-Control-Allow-Origin: *`, a stable ETag, and `Cache-Control`. Matching `If-None-Match` requests return `304`.

Keep the card name and version consistent with live `serverInfo`. Runtime values remain authoritative after connection. Exact non-semver version strings are valid. Version ranges are invalid.

Serve the public card endpoint over HTTPS with TLS 1.2 or later in production. The application host or a TLS-terminating proxy enforces transport security. Remote metadata URLs require HTTPS in production; `environment: 'development'` permits loopback HTTP.

Cards are advisory. Do not include authorization values, embedded secrets, private topology, tools, resources, or prompts. The adapter never fetches a card automatically.
